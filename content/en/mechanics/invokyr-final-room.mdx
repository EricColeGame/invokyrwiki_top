## How the Final Room Sequence Works

Think of the ending as four beats: reach, retrieve, place, speak. Each one is verifiable, and each one can fail independently.

**Reach.** Enter the final room through normal demo progression. Don't treat your first glimpse of the room as proof the ending is armed.

**Retrieve.** Locate the board game. If it isn't with you, walk your route backward until you find it. Reaching the room alone is not the solution.

**Place.** Carry the board game into the end room and confirm it's actually inside — not propped in the doorway or dropped in a neighboring space.

**Speak.** With voice input active, say "Invokyr" clearly and give the game a beat to respond.

| Attempt state | Likely interpretation | Recommended response |
| --- | --- | --- |
| In the last room, board game absent | The object condition is incomplete | Go back and retrieve the board game |
| Board game present, microphone disabled | Voice recognition can't receive the command | Enable voice input in settings |

| Phrase spoken before entering the room | The interaction may not be active yet | Wait until you're inside the end area |
| All conditions met | The demo should be ready | Say "Invokyr" clearly from inside the room |

The most dependable order is **room first, board game second, voice input third, phrase last**. Doing it in that sequence prevents an early voice attempt from being misread as a failed ending.

### Use a controlled retry

Change one variable at a time. Verify the board game, then verify voice input, and only then repeat the phrase. This turns a frustrating loop into a diagnostic: if the ending still won't fire after both conditions are confirmed, you know the problem isn't object placement or voice configuration.

Shouting the phrase repeatedly, by contrast, tells you nothing. You can't tell whether the game heard you and rejected the input, or never heard you at all.

## Voice Input Troubleshooting

Voice input is the technical half of the puzzle, and it's where most failed attempts actually die. Community reports describe players with working microphones who still couldn't finish the demo — because the game's voice-input option was disabled the whole time.

Walk through these checks in order:

- Open the game's settings and confirm voice input is enabled.
- Verify the correct microphone is selected by your system or the game.
- Return to the final room with the board game still present.
- Speak at a normal volume and a measured pace.
- Wait briefly before trying again.
- If it still fails, repeat the object check before anything else.

| Symptom | Most likely check | Practical fix |

| No response to "Invokyr" | Voice input disabled | Enable the setting and retry |
| Mic works elsewhere but not in-game | Wrong input path or game option | Confirm the selected input and in-game voice setting |

The exact menu labels may vary between builds, so focus on the function rather than a specific label. The question that matters is simple: is the game allowed to receive spoken input during the final attempt?

**Hardware is not the same as voice input.** A connected microphone proves nothing about whether the game is listening. Check the in-game option directly before concluding the puzzle is broken.
